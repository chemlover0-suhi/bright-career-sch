## Publish
Recommended:
1. Install VS Code.
2. Test by opening `index.html`.
3. Create a GitHub repository and upload all project files.
4. Import that GitHub repository into Vercel.
5. Deploy.
6. Add a custom domain later if desired.

## Production note
The anthem video is included for this final project. Because video files can be large, production hosting may be faster if the anthem is hosted on a video platform and embedded. Only publish the video with the school's permission.
